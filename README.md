# PREP — 100-Day Developer Revision Platform

> **Learn. Build. Master.**

PREP is a modern, minimal, local-first 100-day software engineering revision platform designed for disciplined technical preparation across backend architecture, cloud infrastructure, full-stack systems, algorithmic problem solving, and generative AI.

---

## 🚀 Features

- **Full 100-Day Curriculum**: All 100 days across 15 technical modules preserved point-by-point from the authoritative syllabus.
- **Hierarchical Syllabus Tree**: Module → Day → Major Topic → Subtopics → Sub-concepts.
- **Independent Revision Checkboxes**: Check off subtopics independently without unwanted cascading changes.
- **5-State Revision Statuses**: Mark topics as *Not Revised*, *Revised*, *Needs Practice*, *Weak*, or *Mastered*.
- **Parallel DSA Track**: Dedicated algorithmic revision section across Arrays, Two Pointers, Trees, Graphs, DP, and interview problem archetypes.
- **Instant Global Search**: Fast fuzzy search across all 100 days, 1,028 subtopics, and module names (`Ctrl+K` / `⌘K`).
- **Local-First & Offline**: All progress persists in `localStorage` with JSON export/import backup functionality.
- **Subtle 3D Minimal Design**: Styled strictly with Pure White (`#FFFFFF`), Charcoal (`#242424`), and Muted Green (`#557B62`).

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Icons**: Lucide React
- **Storage**: Browser LocalStorage (Local-First Architecture)
- **Deployment**: Vercel
